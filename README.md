# Ancient Abilities
![thumbnail](https://cdn.modrinth.com/data/EKfY4mNW/images/728816cab78fdac1edadf31d0ffe6642b535e4ef.png)
A Minecraft datapack that adds abilities and oaths that dramatically change how the game is played. It was made for a private SMP.

## Commands
Run `/trigger ancient_abilities.info` in-game to view information about the datapack, how it works, and the various abilities and oaths.
![info ui](https://cdn.modrinth.com/data/EKfY4mNW/images/7b58b0a3f777b5b8e0bd799b27cbfe2a5da103fc.png)

## Tools Used
* [Visual Studio Code](https://code.visualstudio.com/) - IDE for writing the code
* [Misode Generators](https://misode.github.io/) - generating tiresome parts like JSON recipes and worldgen
* [Minecraft Wiki](https://minecraft.wiki/) - viewing game information such as effects and attributes

## How to Use
You only need vanilla Minecraft to use the datapack since it's not a mod.

1. Download the ZIP file of the respective version from the releases tab
2. Move the ZIP to the `datapacks` folder in your world save folder
3. Save and exit, then enter the world to reload datapacks. You should get a chat message if the datapack successfully loaded

This datapack is also on [Modrinth](https://modrinth.com/project/EKfY4mNW), so you could use that instead.

## AI Use
